# LogiCode — Aprende Lógica de Programación

Aplicación web interactiva para aprender lógica de programación

## Contenido del curso

1. **Fundamentos** — Algoritmos, pseudocódigo y diagramas de flujo
2. **Datos y Operadores** — Variables, tipos de datos y operadores lógicos
3. **Estructuras de Control** — Secuencia, selección (if-else) e iteración (while, for)
4. **Estructuras de Datos** — Arreglos y matrices
5. **Modularidad y POO** — Funciones, clases, objetos y diseño orientado a objetos

## Banco de algoritmos

Incluye **72 ejercicios de algoritmos** organizados por tema, cada uno con guía paso a paso, pistas progresivas, esqueleto de código y enlace al simulador:

| Tema | Ejercicios |
|------|------------|
| Estructura secuencial | 10 |
| Operadores | 8 |
| Selección (Si/SiNo) | 12 |
| Ciclos (iteración) | 14 |
| Arreglos y vectores | 8 |
| Matrices | 6 |
| Funciones y modularidad | 6 |
| Problemas combinados | 8 |

## Ejercicios del libro

Incluye **58 ejercicios propuestos** del libro *Introducción a la Lógica de Programación* (Herrera, Gutiérrez, Pulgarín), organizados por capítulo:

- Cap. 1 Fundamentos (6)
- Cap. 2 Estructura secuencial (6)
- Cap. 3 Estructuras de decisión (9)
- Cap. 4 Estructuras de repetición (17)
- Cap. 5 Procedimientos y funciones (10)
- Cap. 6 Vectores y matrices (10)

## Simulador de pseudocódigo

Ejecuta algoritmos con la sintaxis del libro:

- `leer()`, `imprimir()`, `Si/SiNo/FinSi`
- `Para/FinPara`, `Mientras/FinMientras`, `Haga/MientrasQue`
- Operadores: `Y`, `O`, `MOD`, `^`

## Cómo usar

1. Abre `index.html` en tu navegador (Chrome, Firefox, Edge).
2. Navega por los capítulos desde el menú lateral.
3. Lee cada lección y responde los ejercicios.
4. Marca la lección como completada cuando termines.
5. Tu progreso se guarda automáticamente en el navegador.

### Abrir con doble clic

Haz doble clic en `index.html` para abrir la aplicación directamente.

### Servidor local (opcional)

Si tienes Python instalado:

```bash
python -m http.server 8080
```

Luego visita: http://localhost:8080

## Características

- 13 lecciones interactivas con teoría y ejercicios
- 72 ejercicios en el banco de algoritmos (todos los temas)
- 58 ejercicios del libro con seguimiento de progreso
- Simulador de pseudocódigo integrado
- Seguimiento de progreso (localStorage)
- Diseño responsive para móvil y escritorio
- Sin dependencias — funciona sin instalar Node.js
